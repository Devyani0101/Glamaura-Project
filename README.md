# Glamaura-Project💄✨

Overview

Glamoura is a modern beauty and cosmetics web application designed to provide users with an interactive and user-friendly shopping experience. The project focuses on delivering an elegant interface, smooth navigation, and efficient backend functionality.

---

Features

- User-friendly and responsive interface
- Beauty & cosmetic product management
- Secure backend integration
- Database connectivity using PostgreSQL
- Dynamic web pages using Thymeleaf
- Clean and modern UI design

---

Technologies Used

Frontend

- HTML5
- CSS3
- Thymeleaf

Backend

- Java
- Spring Boot

Database

- PostgreSQL

How to Run the Project

1. Clone the repository
2. Open the project in your IDE
3. Configure PostgreSQL database
4. Run the Spring Boot application
5. Open the application in browser
